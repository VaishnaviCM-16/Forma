# Third-party image sources

## Night Sky theme

The Night Sky theme uses a locally optimized copy of “Night sky with stars and clouds” by Denis Sobnakov (`@sobden`). Source: [Unsplash photo page](https://unsplash.com/photos/night-sky-with-stars-and-clouds-o2V2RJZLP60). The photo page identifies the image as available under the [Unsplash License](https://unsplash.com/license). The derivative is used as a subtle canvas background. This does not imply endorsement by the photographer or Unsplash.

## Wikimedia Commons picker

Image search is a direct browser request to the [Wikimedia Commons Action API](https://www.mediawiki.org/wiki/API:Search); file metadata follows [API:Imageinfo](https://www.mediawiki.org/wiki/API:Imageinfo). Results can include contributor-supplied creator, license and source-page data. Metadata may be incomplete or incorrect; users should verify the specific work's terms before use. See the [Commons licensing guide](https://commons.wikimedia.org/wiki/Commons:Licensing) and [API etiquette](https://www.mediawiki.org/wiki/API:Etiquette). Imported images are compressed into the active in-memory room and are not durably stored.
